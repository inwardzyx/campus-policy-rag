# 闭环"变好"验收协议（2026-10-28）

> 为什么要有这一页：我们的闭环能**拦坏候选**、能**跑通**，但**没有证据能说"变好了"**。
> 这不是实现问题，是**证据结构**问题。本协议把"变好"定义成可执行、可反驳的判据。

## 0. 当前状态（诚实）

| 项 | 现状 |
|---|---|
| 闭环机制 | ✅ 可用（mine → 候选 → 配对门禁 → active/回滚） |
| 门禁拦坏候选 | ✅ 有一次实证（6 gain / 11 loss 被拒） |
| "变好"证据 | ❌ **没有**：+1 增益 < 同日波动 ±2，McNemar **p=1.0** |
| 原因 | ① 候选在同一套题上挖、同一套题上验收（过拟合）；② 候选是整句匹配（泛化=0）；③ 主指标是"检索命中"不是答案正确；④ n 太小、波动大 |

## 1. 预注册（跑之前写死，跑完不许改）

| 项 | 取值 |
|---|---|
| 主指标 | `answer_value`（数值题值命中率）；没有值时用 `answer`（检索命中）并**明确降级** |
| 辅助指标 | `context_recall`、`nDCG@3`、`p95_ms` |
| 验收集 | **held-out**（冻结候选后才拿到的新题） |
| 显著性 | 精确 McNemar 双侧 `p < 0.05`，**且** 配对 Δ 的 bootstrap 95% CI 下界 > 0 |
| 最小净翻转 | 46 题规模下，**净修好 ≥ 6 题**才可能显著（+5/0 的 p≈0.063） |
| 护栏 | ① 回归集不掉；② 拒答率不回退；③ 无 `acl_leak`；④ p95 不超基线 1.5× |
| 重复次数 | 每臂 **K=3** 次，逐题取多数 |

## 2. 三份数据（不许混用）

| 集合 | 来源 | 可见性 | 用途 |
|---|---|---|---|
| **dev**（46 题 company-52） | 已有 | 可反复看 | 挖候选、调参 |
| **regression** | dev 中原本答对的题 | 每次跑 | 防回归 |
| **held-out**（≥10 题） | **真实用户问题**（辅导员/体育委员/同事） | 候选冻结后才拿到 | **唯一允许声称"变好"的集合** |

**硬规则**：
- held-out 的题**不许**进 `mine()`；
- held-out **不许**在调参期间跑；
- 自己出的"新题"不算 held-out（你写题时已经知道系统会怎么答）。

## 3. 运行协议

1. 两臂必须同 `state_fingerprint`（代码 + 环境 + 语料一致）；不一致直接判"不可比"；
2. 每臂跑 K=3 次（同一题集、同一服务配置）；
3. 逐题取多数（> K/2 才记 ok）；
4. 只比**逐题翻转**：`fixed`（错→对）、`broke`（对→错）、`unchanged`；
5. 计算 `Δ = (fixed - broke) / n`、McNemar p、bootstrap CI（5000 次，seed 固定）；
6. 四道护栏逐项检查。

## 4. 判据（全部满足才算"变好"）

```
verdict = "有证据"
  iff  p < 0.05
   and CI_low(Δ) > 0
   and 回归集不掉
   and 拒答率不回退
   and acl_leak == 0
   and p95_after <= 1.5 * p95_before
否则 = "无证据"（不许写"略有提升"）
```

## 5. 候选的形态限制（防止"记住答案"）

只有**通用规则**能声称提升：

| 允许 | 不允许 |
|---|---|
| 同义词/别名表 | 整句问题匹配（只对那一句生效） |
| prompt 约束 | 针对某题的硬编码 |
| 切块/索引策略 | 改 gold 让它"对" |

验证泛化：把 held-out 题改写成 2–3 种问法，候选必须在**改写后的问法**上也有效。

## 6. 报告模板

```markdown
# 闭环验收：<候选 id>
- 数据：held-out n=14（来源：辅导员 2026-10-30）
- 指纹：before 83e7cc655f4a / after 83e7cc655f4a（一致 ✓）
- K=3，多数投票
- 翻转：fixed=7 broke=1 unchanged=6
- Δ=0.429  bootstrap 95% CI [0.071, 0.786]
- McNemar p=0.070（不显著）
- 护栏：回归 0 掉 / 拒答 0 退 / leak 0 / p95 1.1×
- 结论：**无证据**（p 未过线）
```

## 7. 工具

`scripts/paired_eval.py` 按本协议算：指纹校验、K 次多数、翻转表、McNemar、bootstrap CI、四护栏。
结论 `"无证据"` 时退出码 2（空转/证据不足必须报红，不许报绿）。
